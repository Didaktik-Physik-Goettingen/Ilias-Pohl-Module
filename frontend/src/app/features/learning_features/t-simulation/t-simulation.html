DGLs numerisch lösen

Für die Differentialgleichung des harmonischen Oszillators ist es möglich eine analytische Lösung herzuleiten. Aber dies gilt natürlich nicht für alle Differentialgleichungen – in einigen Fällen ist eine numerische Lösung daher unabdingbar.

In diesem Versuch werden Sie ein Jupyter Notebook als Grundlage erhalten, um zwei unterschiedliche Methoden auszuprobieren:

Euler-Verfahren

Die simpelste Näherung, die auf dem Differenzenquotienten basiert.

Runge-Kutta-Verfahren (RK4)

Dieses Verfahren nutzt zusätzliche Stützstellen, um den jeweils folgenden Punkt zu berechnen, und wird an vielen Stellen auch in wissenschaftlichen Kontexten verwendet.

Weitere Informationen und Anleitungen zu den unterschiedlichen Verfahren finden Sie in dem Jupyter Notebook, dass Sie unten herunterladen können. Sie können entweder jetzt einen Blick in das Notebook werfen, oder zunächst das Lernmodul abschließen und sich anschließend mit dem Code beschäftigen.
